# Presets

A preset is a named camera position, such as *Wide shot* or *Lectern*.

- **Save new**: frame the shot, press **New** and give it a name.
- **Go to a preset**: double-click it, select it and press ▶, or press its number key
  (`1` to `9`).
- **Update**: stores the current position into the selected preset.
- **Rename** and **Delete** the selected preset.
- **▲ / ▼**: reorder the list. This changes which number key recalls each preset.

## Where presets are stored

- **VISCA mode**: in the camera's memory, slots 1 to 89. Slots from 90 upward are avoided
  because many cameras use them for special functions, such as opening the on-screen menu.
- **UVC mode**: the absolute position is stored on the computer, in `presets.xml` (see
  [Settings files](./settings.md)).

The names and the order of the list are always stored on the computer.
